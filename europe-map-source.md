# Europe map source

The regional map uses real country geometry from the `leakyMirror/map-of-europe` GeoJSON dataset, derived from Natural Earth country boundaries.

Source: https://github.com/leakyMirror/map-of-europe/blob/master/GeoJSON/europe.geojson

The application uses this geometry only for geographic context and interaction. Water-pressure values continue to come from the prototype's labelled mock regional dataset; countries without prototype indicators are shown as neutral context.
